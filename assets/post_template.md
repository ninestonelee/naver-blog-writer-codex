## 발행 체크
- [ ] 모바일 화면 보기 → Ctrl+Shift+V
- [ ] `##` → 인용구/소제목, `**` → 볼드, 생성한 이미지 수와 배치 확인
- [ ] HTML 본문 마지막에 # 포함 해시태그 8개, 별도 태그는 # 없는 쉼표 한 줄
- [ ] 카테고리 지정 → 발행 (사람이 클릭)
- [ ] 유사문서율 확인, 로그 1줄
