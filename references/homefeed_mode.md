# 홈판(홈피드)형 글쓰기 규칙

홈피드는 네이버 앱 홈 하단의 개인화 추천 지면이다. 검색 순위·블로그 지수보다 **개별 글의 클릭률 → 체류 → 반응(공감·댓글·공유)** 이 노출을 결정한다. 노출 로직은 비공개이며 재현 공식은 없다. 아래는 확률을 올리는 규칙이다.

## 1. 6가지 감정 트리거 — 소재 하나에 최소 2개

| 감정 | 작동 방식 | 제목 골격 |
|---|---|---|
| 놀람 | 상식과 반대되는 사실 하나 | 「○○인 줄 알았는데 사실은 △△였다」 |
| 공감 | 독자의 경험을 그대로 호명 | 「아들딸 둔 부모라면 남의 일 아닙니다」 |
| 불안 | 기한·손실·나만 모르는 것 | 「지금 안 하면 1년 뒤 후회하는 ○○」 |
| 존경(반전 인생) | 바닥 → 정상의 낙차 | 「인맥 하나 없던 ○○가 △△ 된 이유」 |
| 호기심 | 답을 제목에서 감춤 | 「그다음에 어떻게 됐을까요」 |
| 실용 | 루틴·공식·체크리스트 | 「여름 근육 유지 루틴 공개합니다」 |

## 2. 홈판 9대 주제 — 반응도와 리스크

| 주제 | 반응 | 광고 단가(상대) | 반드시 적용할 리스크 규칙 |
|---|---|---|---|
| 방송·연예 이슈 | 최고 | 중 | 초상권·명예훼손·사진 저작권 — legal_check 1·2·3 |
| 리빙(다이소·코스트코·올영) | 높음 | 중 | 협찬·구매 유도 시 대가성 표기 |
| 경제·재테크 | 높음 | 높음 | 투자 조언 아님 문구, 수익 보장 금지 |
| 스포츠 | 높음 | 중 | 속도전, 사실 확인 |
| 자동차 | 중 | 높음 | 낮음 |
| 건강·의학 | 중 | 중~높음 | 효능·치료·예방 단정 금지 — legal_check 4 |
| 지식·교양(심리·인간관계·처세·어록) | 중, 스테디 | 낮~중 | 어록 통째 전재 금지, 인용 3 : 해석 7 |
| 교육·학문 | 낮음 | 낮음 | 낮음 |
| 여행 | 낮음 | 낮음 | 소재 소진 빠름 |

지식교양은 저작권·속보 부담이 없어 장기 운영에 유리하다. 연예·건강·경제는 반응이 크지만 리스크 규칙 없이는 쓰지 않는다.

## 3. 제목 3단 구조

```
[장면: 누가·언제·어떤 상황]  +  [반전: 예상과 다른 사실]  +  [궁금증: 그래서 어떻게?]
```
- 첫 7~12자 안에 장면이 보여야 한다 (모바일 목록에서 잘리는 구간)
- 예: 「평생 가족을 위해 벌었는데, 딸 돈은 아들 재산이 되고 딸에겐 빚까지 떠안긴 부모 — 그 여배우」

## 4. 제목 패턴 5종 + 공분형

| 패턴 | 골격 | 예시 |
|---|---|---|
| 반전형 | ○○인 줄 알았는데 사실은 △△ | 부자인 줄 알았는데 사실은 신용불량자였습니다 |
| 숫자형 | 3위·2위는 공개, 1위는 의외 | 은퇴 후 후회 3위 저축, 2위 건강, 1위는 전혀 다른 거였습니다 |
| 경고형 | 이것만은 하지 마세요 / ○○가 △△한 이유 | 50대에 이것만은 하지 마세요, 3년 뒤 갈라집니다 |
| 인생장면형 | 그날 모든 게 바뀌었습니다 / ○○의 선택 | 퇴직 통보받은 날, 모든 게 바뀌었습니다 |
| 감추기형 | 이름·상품명·비결을 숨김 | 전성기 끝난 줄 알았는데 임신 중 복대 차고 버틴 그 여배우 |
| 공분·도발형 | 이게 말이 됩니까 / 속마음 대변 | ○○ 사태보다 더 무서운 질문이 나왔다, 팬들이 폭발한 진짜 이유 |

**감추기형 의무**: 감춘 것(이름·상품·비결)은 본문 **첫 번째 인용구 직후**에 공개한다. 안 풀면 낚시가 되어 이탈이 쌓이고 다음 글 노출이 줄어든다.
**공분형 의무**: 사실 확인 없는 단정 금지. "~라는 지적이 나왔다(출처)", 의문문 구조로 쓴다.

## 5. 검색형 → 홈판형 변환 예

| 소재 | 검색형 | 홈판형 |
|---|---|---|
| 도수치료 | 도수치료 효과와 비용 정리 | 도수치료 10번 받고 알았습니다, 병원이 말 안 해주는 것 |
| 실비보험 | 실비보험 4세대 전환 조건 | 실비 갈아탔다가 후회한 사람들의 공통점 하나 |

## 6. 제목 5문항 체크 (4개 이상 ✔이면 채택)

| # | 질문 | ✔ 기준 |
|---|---|---|
| 1 | 첫 7~12자 안에 장면이 보이는가 | 명사+동사로 그림이 그려짐 |
| 2 | 누가·왜·내가 드러나는가 | 독자가 자기 일로 읽음 |
| 3 | 같은 소재의 다른 글과 한눈에 다른가 | 상위 5개 제목과 비교 |
| 4 | 제목의 약속을 본문이 지키는가 | 감춘 것을 본문에서 푼다 |
| 5 | 과장 표현이 없는가 | 충격·경악·역대급·소름 0개 |

## 7. 본문 스펙

- 1,400~1,600자, 첫 문장은 사건 한가운데 ("처음에는 웃었습니다.")
- 목차 없음. 인용구 5개(`## ` 접두)로 흐름을 나눈다. 인용구는 한 줄 20자 이내
- 이미지 5장 자리(인용구 아래마다)
- 운영자 감상 문장 + 1인칭 문장 3개 이상
- 마지막 문단은 독자에게 던지는 질문
- FAQ 3개
- 홈판 소재는 네이버 안에서 찾는 것이 정합성이 높다: 네이버 뉴스 랭킹(엔터·스포츠·경제), 최신뉴스 "1분 전", 크리에이터 어드바이저 트렌드, 카페 댓글의 질문·갈등, 내 과거 글 제목 리뉴얼
