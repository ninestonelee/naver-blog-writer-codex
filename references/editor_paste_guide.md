# 스마트에디터로 옮기기

## 일반 텍스트·마크다운

- 제목과 본문을 분리해 옮긴다. 본문을 서식 없이 붙여넣으면 마크다운 표기 자체는 남을 수 있으므로 `##`와 `**`를 제거하고 편집기의 소제목·인용구·볼드로 다시 지정한다.
- 생성한 썸네일과 본문 이미지를 번호 순서에 맞춰 삽입한다.

## HTML 결과물

- HTML은 브라우저에서 먼저 열어 디자인을 확인한다. HTML 소스 코드를 일반 본문 입력란에 붙이는 방식과 렌더링된 글을 복사하는 방식을 구분한다.
- 렌더링된 제목·본문을 옮긴 뒤 실제 편집기에서 서식을 확인한다. 글꼴·여백·배경·인용 서식이 그대로 유지된다고 보장하지 않는다. 필요한 부분은 편집기 기능으로 맞춘다.
- 이미지 자리표시자를 해당 번호 파일로 교체하고, 번호·파일명·삽입 안내 문구가 발행 본문에 남지 않게 정리한다. 로컬 이미지가 자동 업로드됐다고 가정하지 않는다.
- 모바일 미리보기에서 문단 간격·글자 크기·이미지 배치를 확인한다.

## 마무리

- HTML 본문 마지막의 `#` 포함 해시태그 영역은 유지한다. 이미지 번호·파일명 등 편집 안내만 정리한다.
- 발행 창에 사용할 태그는 본문과 별도로 `#` 없이 쉼표로 구분한 한 줄로 전달한다. 실제 태그 입력 결과는 편집기에서 확인한다.
- 제목·카테고리·공개 범위를 점검한다. 이 스킬의 글·HTML·이미지 제작은 실제 발행 요청이 아니다.
